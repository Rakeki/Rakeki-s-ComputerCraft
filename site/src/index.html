Turtles that dig, build & report back.

A set of Lua programs for ComputerCraft turtles and computers. They carve out halls, strip-mine, raise whole villages, build mob farms, run an AutoMine fleet and put everything on one live dashboard. They all pick up where they left off after a reboot.

IntegrationHow it all fits together

          
Every program works on its own. Add a modem and they start talking: miners take jobs from the AutoMine server, GPS keeps turtles on course, and the dashboard shows everyone.

Getting it in-gameThree ways to install

          
Paste into any computer or turtle with Ctrl+V. Needs http enabled in the ComputerCraft config, which it is by default.

        

        

          

            1 · Easiest
            
The installer

            
One line fetches the program and the libraries it needs, and saves itself as install so install update gets newer versions later.

            

          

          

            2
            
wget each file

            
Every program page lists a wget line per file, for when you only want one file or want to see exactly what goes where.

            

          

          

            3
            
Download & copy

            
Grab a ZIP from any program page. Unzip it into saves/<world>/computercraft/computer/<id>/, or drag the files onto the computer's screen to upload them.

            
saves/world/computercraft/computer/id/
